# SensorProject
Ultrasonic sensor project for the Hackathon

This repository contains an "Ultrasonic sensor project for the Hackathon".

This project utilizes an Arduino Uno and an ultrasonic sensor to create a simple, real-time distance detector. It features a dual-LED indicator system that provides instant visual feedback based on object proximity:

Close Range: One LED lights up when an object is detected closer than 10 centimeters.
Far Range: The second LED illuminates when no object is detected within the 10-centimeter threshold.
